# Market Receipt

파이널판타지14 장터(마켓보드)에서 구매한 아이템을 자동으로 기록하는 달라무드 플러그인입니다. 한국 서버 달라무드(API 15) 기준으로 작성했습니다.

## 설치

1. 게임 안에서 `/xlsettings` → 실험적 기능 → 커스텀 플러그인 저장소에 아래 주소를 추가하고 저장합니다.

   ```
   https://raw.githubusercontent.com/hyeon-days/ffxiv_market_receipt/main/repo.json
   ```

2. `/xlplugins`에서 **Market Receipt**를 검색해 설치합니다.

## 사용

`/mreceipt`로 기록 창을 엽니다. 창 제목 줄의 정보 아이콘을 누르면 사용법이 열립니다.

- **위쪽:** 기간과 아이템 이름으로 걸러 보고, 정렬(최신순, 오래된순, 총액 높은순, 아이템 이름순, 종류별, 라벨별)을 바꿉니다. 오른쪽 '자동 라벨링' 버튼으로 자동 라벨링을 켜고 끕니다.
- **가운데:** 구매 기록 표입니다. 아이템 아이콘이 함께 보이고, 아이템 이름에 마우스를 올리면 분류, 서버, 세금이 나옵니다. 표 머리의 '라벨'을 누르면 라벨로 거를 수 있습니다.
- **아래쪽:** 왼쪽에 '라벨 관리', 'CSV 폴더 열기', '시트 연결', 오른쪽에 합계가 항상 고정되어 있습니다. 합계는 선택한 기록이 있으면 선택한 것만, 없으면 지금 걸러진 기록 전체를 더한 값입니다.

기록 파일은 달라무드 플러그인 설정 폴더의 `MarketReceipt\purchases.csv`에 쌓이며, 엑셀에서 한글이 깨지지 않도록 UTF-8 BOM으로 저장합니다. 구매할 때마다 채팅창에 확인 메시지가 한 줄 뜹니다.

## 라벨링

'부대 공금'처럼 구매 기록에 라벨을 붙여 용도별로 묶는 기능입니다. 라벨 필터로 걸러 보거나 CSV에서 라벨별로 모아볼 수 있습니다.

- **라벨링 하는 법:** 표에서 기록을 눌러 선택하면 아래쪽에 선택 바가 나타납니다. 드롭다운에서 라벨을 고르고 '변경'을 누르면 적용되고, 드롭다운의 '라벨 제거'로 라벨을 뗄 수 있습니다. 표 맨 위 체크박스는 지금 보이는 기록 전체를 선택합니다.
- **자동 라벨링:** 켜두면 이후 장터 구매에 고른 라벨이 자동으로 붙습니다. 켜져 있는 동안 버튼이 초록색으로 표시됩니다.
- **라벨 관리:** 라벨 추가, 이름 변경(입력 후 엔터), 색 변경(색 견본 클릭), 삭제를 할 수 있습니다. 이름을 바꾸면 과거 기록에도 함께 반영됩니다.

## 스프레드시트 내보내기

선택한 기록을 구글 시트로 보낼 수 있습니다. 시트 주소만으로는 플러그인이 시트에 쓸 수 없어서, 시트에 작은 스크립트(Apps Script)를 붙이고 그 주소를 연결하는 방식입니다.

1. 기록을 받을 구글 시트를 열고 확장 프로그램 → Apps Script를 엽니다.
2. 플러그인 왼쪽 아래 '시트 연결' → '스크립트 복사'를 누르고, 편집기 내용을 지운 뒤 붙여넣고 저장합니다.
3. 배포 → 새 배포 → 유형 '웹 앱', 실행 사용자 '나', 액세스 권한 '모든 사용자'로 배포합니다. 처음 한 번은 구글 계정 권한 허용이 필요합니다.
4. 나온 웹 앱 URL(`https://script.google.com/macros/s/…/exec`)을 '시트 연결' 칸에 붙여넣고 저장합니다.

이후 기록을 선택하고 '시트로 내보내기'를 누르면 시트의 '구매 기록' 탭에 한 줄씩 추가됩니다. 첫 열의 키로 이미 보낸 기록을 걸러내므로, 같은 기록을 다시 보내도 중복으로 쌓이지 않습니다. 웹 앱 주소를 아는 사람은 누구나 시트에 줄을 추가할 수 있으니 주소는 공유하지 마세요.

## 기록 방식

구매 버튼을 누르는 순간 아이템, 수량, 단가, 세금, 현재 서버를 잡아두고, 서버가 구매 성공을 알려오면 둘을 짝지어 한 줄로 기록합니다. 다른 사람이 먼저 사서 실패한 구매는 성공 신호가 오지 않으므로 기록되지 않습니다. 플러그인은 게임 데이터를 읽기만 하며, 게임에 아무것도 보내거나 바꾸지 않습니다.

## 새 버전 배포

1. `MarketReceipt.csproj`의 `Version`과 `repo.json`의 `AssemblyVersion`을 같은 값으로 올립니다. `repo.json`은 네 자리(예: 0.1.1.0)로 적어야 합니다.
2. main에 푸시하면 깃헙 액션이 빌드해 그 버전 번호로 릴리스를 만들고 `latest.zip`을 올립니다.

## 주의

달라무드 플러그인 사용은 스퀘어에닉스 이용약관에 어긋나며, 사용에 따른 책임은 본인에게 있습니다.
